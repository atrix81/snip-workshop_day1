# Snip Frontend

The Angular 19 web client for Snip. It creates short links and lists visits using the backend API at `http://localhost:3000`.

## Run locally

Start the backend, then run:

```sh
npm install
npx ng serve
```

The development app is available at `http://localhost:4200`.

## Build

```sh
npx ng build
```

The production browser app is written to `dist/snip-frontend/browser`.
